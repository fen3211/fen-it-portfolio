# ЭКО-ЭКСПЕРТ — полный сайт

Запуск: откройте index.html или `python -m http.server` в папке.

## Редактирование без программиста
- Вариант A (сейчас): правите тексты прямо в HTML или в `content/`.
- Вариант B (CMS): залейте на Netlify/VPS, включите Decap CMS (`/admin/`), подключите git-gateway. Коллекции: услуги, кейсы, сотрудники, статьи, документы.
- Альтернатива для РФ: тот же фронт + Directus/Strapi/Bitrix как API.

## Формы
`form[data-lead]` шлёт POST на `/api/lead`. Подключите: Formspree / Getform / свой PHP (`move_uploaded_file` для файлов до 50МБ) / Bitrix-вебхук. Валидация и трек-номер уже есть.

## SEO/аналитика
- meta/OG/sitemap/robots/schema уже встроены.
- Вставьте Яндекс.Метрику + GA4 перед `</body>` (помечено комментарием).
- Каждая услуга — отдельный URL /services/<slug>.html под расширение.

## Что доделать до продакшена
1. Заменить телефон/почту/адрес, вставить iframe карты.
2. Положить реальные PDF в /assets/docs, сканы лицензий в docs.html.
3. Сжать изображения в webp, видео — muted+preload.
4. Подключить бэкенд форм и проверку файлов (clamav / лимиты).
