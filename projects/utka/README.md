# UTKA — приложение лояльности кофеен

Тестовое задание: премиальный мобильный дизайн приложения кофейной лояльности с 3D-персонажем-уткой.
Один главный экран в двух состояниях: до первого визита и после трёх визитов.

## Что здесь

| Путь | Что это |
|---|---|
| `index.html` | Приложение: чистый экран (корень сайта). Демо-панель — по `?demo=1`, скриншотный режим — `?capture=1` |
| `about.html` | Страница-презентация проекта |
| `system.html` | Живая дизайн-система: токены, типографика, компоненты |
| `data.js` | Все тексты и данные двух состояний — единственное место для правки контента |
| `styles/app.css` | Дизайн-система: CSS-токены в начале файла, дальше компоненты |
| `app.js` | Рендер состояния по `data.js`, шторки (QR, помощь, банка, купоны, чат) |
| `assets/fonts.css` | Локальные шрифты Manrope + Cormorant Garamond (кириллица) |
| `assets/utka-duck-base.png`, `utka-duck-apron.png` | 3D-рендеры утки, прозрачный PNG, 660×1240 |
| `assets/utka-avatar.png` | Аватар для чата |
| `exports/screens-2x/`, `exports/screens-3x/` | PNG-экспорты обоих экранов (обычный и «весь контент» варианты) |
| `exports/utka-presentation.png` | Доска: два экрана рядом для сравнения |
| `raw/` | Служебные скрипты (скриншоты, QA) — не часть доставки |

## Запуск

**Живая версия: https://fen3211.github.io/utka/** — открывается сразу чистый экран приложения. Презентация: `/about.html`, дизайн-система: `/system.html`. Переключение состояния — клавиши 1/2.

Проще всего — без сервера: откройте двойным кликом `index.html` (приложение) или `about.html` (презентация). Все шрифты и изображения лежат локально и подхватываются сами.

Для полного варианта (переключение состояний через адресную строку):

```bash
cd "D:\Projects\дип сик\utka"
python -m http.server 4174 --bind 127.0.0.1
```

- Приложение: http://127.0.0.1:4174/ (демо-панель: `/index.html?demo=1`)
- Переключение состояний: кнопки в демо-панели, клавиши 1/2 или параметр `?state=guest|regular`
- Презентация: http://127.0.0.1:4174/about.html

## Как править

1. **Тексты и данные** — `data.js`, объекты `guest` и `regular`. Тексты брифа внесены дословно, менять их в прототипе не требуется.
2. **Цвета, шрифты, радиусы, отступы** — токены `:root` в начале `styles/app.css`.
3. **Структуру блоков** — разметка в `index.html`, стили компонентов ниже токенов в `app.css`.
