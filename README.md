## Локальный запуск

Из корня проекта:

```bash
python serve.py
```

Открыть [http://127.0.0.1:4173/](http://127.0.0.1:4173/). `serve.py` использует `ThreadingHTTPServer`: NOVA Gear одновременно подгружает 56 WebP-кадров, и одиночный `http.server` может отказывать в соединениях. Сборка и npm-зависимости для главной не нужны.

Проверка JS:

```bash
node --check assets/js/site.js
```

## Сборка проектов

Главная — статика, собирать нечего. Для Vite-проектов (Oyun, Eclipse) сборка уже лежит в `projects/`. Если исходники обновились:

```bash
cd <source-repo>
npm install
npm run build -- --base=./
# скопировать dist/* в projects/<slug>/
```

`base: "./"` обязателен: сайт живёт по пути `/fen-it-portfolio/`, а не в корне домена. Статические проекты (EscrowHub, NOVA, Utka) просто копируются в `projects/<slug>/` с сохранением относительных путей.

**Не использовать Git Submodules.** Проекты физически лежат в репозитории. Секреты, `.env`, токены и личные данные не переносились. Тяжёлые служебные папки исходников (review, kwork_portfolio, scripts, tests, exports 3x) исключены; подробности — в [`projects/README.md`](projects/README.md).

## Как добавить проект

1. Положить демо в `projects/<slug>/`; проверить относительные пути и отсутствие абсолютных `/assets/...`.
2. Снять превью с реального демо (Playwright) и положить в `assets/img/previews/`, кадры кейса — в `assets/img/cases/`.
3. Добавить строку в hero-индекс и карточку в `#works` (`index.html`); указать `data-category` (`web`, `ui`, `mobile`).
4. Создать `work/<slug>.html` по образцу существующих кейсов; обновить `sitemap.xml`.
5. Проверить ссылки, alt, консоль, ширины 360–1920.

## Вьюер прототипов

На карточке **SMS PRO** в лаборатории есть кнопка **«Смотреть макет»** — она открывает встроенный Framer-подобный вьюер прямо на сайте.

- **29 страниц** и **57 экранов** (desktop 1200 + phone 390), снятых через Framer MCP; данные — `assets/img/prototypes/sms/manifest.json`.
- Редакторская часть: панель страниц с поиском и миниатюрами, canvas с pan/zoom, переключение Desktop/Phone, Fit, `+`/`−`, `0`.
- **Прототип:** отдельный режим с браузерной/телефонной рамкой, скроллом страницы и реальными хотспотами. Клик по карточке/ссылке переходит на целевую страницу, работают «Назад» и «На главную».
- Хотспоты есть там, где в Framer лежат настоящие link-ноды (на главной — 43: карточки, сервисы, страны, статьи, CTA). Навигация и часть CTA в прототипе — кодовые компоненты Framer, их ссылки недоступны через API, поэтому на остальных страницах переходы идут через панель «Страницы».
- Горячие клавиши: `Esc` — выйти из прототипа/закрыть, `←`/`→` — страницы, `+`/`−`/`0` — масштаб, `P` — прототип, `/` — поиск.
- Ссылка `?proto=sms` открывает вьюер сразу; `Framer ↗` ведёт в редактор (нужен доступ).
- Вьюер не публикует Framer-проект: это статичные рендеры + навигация по реальным ссылкам макета.

## Волновой фон и мини-карточки

- В секции **«Выбранные работы»** за контентом живёт canvas с частицами: спокойное поле точек, которое рябит от курсора, как вода. Волны расходятся от указателя, есть лёгкое вращение и впадина под курсором. Эффект вдохновлён Riff «Cursor Follow Interaction» (Hardik Gondhiya), но переосмыслен как фон, а не летающий объект.
- Canvas рисуется только когда секция в зоне видимости, считает точки по видимому окну и отдаёт статичный кадр при `prefers-reduced-motion`.
- Клик по работе открывает **мини-карточку**: превью, категория/год, название, описание и переход в кейс. Закрытие (×, Esc или клик по фону) затягивает карточку в крестик, как в чёрную дыру (transform-origin в точке X, поворот и collapse до scale .03), и запускает световой всполох — лучи, частицы и вспышку в палитре лайм/кобальт. Шапка сайта остаётся видимой над затемнением. Это переосмысленный Riff «Making dismissing things more fun».
- Мини-карточка — диалог с focus trap, возвратом фокуса на карточку работы и закрытием по Esc; при reduced motion вспышка отключается.

## Известные ограничения

- Ссылки `Framer ↗` ведут в редактор и требуют доступа к проекту. SMS PRO открывается во встроенном вьюере со всеми страницами; EMBER и Real Lot пока показываются статичными скриншотами.
- Проект Framer называется **Real Lot**, но его страница — **Freelance Radar**; это отражено в подписи, без выдуманных названий.
- Демо проектов — концепты и тестовые задания, без реального бэкенда/оплаты. Границы обозначены в каждом кейсе и в самих демо.
- Точные Motion-кривые из Figma Riffs не извлечены: для этого нужна копия frame в Motion timeline. Наблюдения и приблизительные тайминги — в `ANIMATION_REFERENCES.md`.
- Внешние ссылки внутри демо (например, правила EscrowHub.online) ведут на реальные публичные страницы сервиса.
- В SMS PRO строка «Для любого сервиса.» переведена с `Switzer Italic` на **Inter Italic 600**: у Switzer нет кириллицы, поэтому Framer подставлял системный serif. Inter уже был в проекте и даёт близкий гротескный италик с кириллицей. Это единственное изменение в Framer-проекте.
