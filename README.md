# FEN — дизайн и код

Статическое портфолио на HTML/CSS/JavaScript. Редизайн Blue Studio: кобальтовая сетка, лаймовые акценты и собственная SVG-графика.

## Локальный просмотр

Из корня проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/ . Сборка и npm-зависимости не нужны.

## Структура

- `index.html` — главная.
- `assets/css/style.css` — токены, компоненты, адаптив и reduced motion.
- `assets/js/main.js` — доступное меню, копирование email и Метрика.
- `assets/img/studio/` — авторские SVG-предметы.
- `assets/img/cases/` — снимки собственных проектов.
- `assets/og-card.html` — исходник обложки; `og-image.png` — снимок 1200 × 630.
- `demo/` — отдельные демо Эко-эксперта и Atlaxis.
- `docs/redesign-direction.md` — направление и референсы.
- `docs/verification.md` — выполненная проверка и её ограничения.

## Проверка перед публикацией

```powershell
node --check assets/js/main.js
git diff --check
```

Проверить главную на телефоне и десктопе, ссылки на демо, меню, details/summary и email. После изменения первого экрана обновить `og-image.png` из `assets/og-card.html` при размере окна 1200 × 630.

Метрика включается только на `fen3211.github.io`; локальные просмотры не попадают в статистику. При переносе на другой домен обновить условие hostname, canonical/OG URL, robots.txt и sitemap.xml.

Эко-эксперт — концепт экспертного бюро с девятью направлениями, проектными сценариями и формой локальной подготовки брифа. Atlaxis — концепт медицинского кабинета с вкладками, выбором формата встречи и чек-листом. Объекты и данные условные; брифы и заметки не отправляются.

Демо не содержат подключённого бэкенда заявок или медицинского AI. GitHub Pages обслуживает только статические файлы. Снимки обновлённых демо — в assets/img/cases/, полные страницы и мобильные превью — в docs/previews/.
