# FEN — Blue Studio

Главный референс: https://www.behance.net/gallery/254802235/Portifolio-Design-Grafico-2026-Felps-Designer

## Направление

Рабочий стол дизайнера: кобальтовая сетка, крупная белая типографика, лаймовая рамка выделения, оранжевые стикеры, объёмные канцелярские предметы. Графику делаем свою; референс задаёт композиционный язык.

## Структура

1. Первый экран: PORT/FOLIO, FEN, позиционирование «Дизайн и код», две основные ссылки.
2. Избранные работы: реальные снимки Эко-эксперта, Atlaxis и графического портфолио, контекст каждого проекта, ссылки на демо.
3. О FEN: карточка автора без выдуманного портрета, стек, условия работы.
4. Форматы: лендинг, корпоративный сайт, редизайн с текущими ценами.
5. Процесс: пять шагов от брифа до передачи исходников.
6. Контакт: Telegram, почта, копирование адреса с честным состоянием результата.

## Ограничения

- Статический HTML/CSS/JS и совместимость с GitHub Pages сохраняются.
- Демо не переделываются. Эко-эксперт обозначен как демо; CMS и бэкенд форм требуют подключения.
- Настоящие ссылки, без перехвата навигации ради эффектов.
- Доступное мобильное меню, клавиатурный фокус, учёт reduced motion, работоспособность без JS.
- Метаданные и существующий счётчик Метрики сохраняются. На localhost счётчик не запускается.
- Публикация в GitHub Pages не входит в локальную подготовку редизайна.
